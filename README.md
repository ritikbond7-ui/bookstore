# Bookstore - BCS353 Web Designing Workshop

Open `index.html` in a browser (internet needed once for the Bootstrap and Google Fonts CDNs).

Frame structure (index.html): top frame = top.html, left frame = left.html, right frame (name="content") = home.html at start.
Links in the top and left frames use target="content", so pages load in the right frame.

| File | Purpose |
|------|---------|
| index.html | Frame layout (top / left / right) |
| logo.png | Logo shown in the top frame (replace this file to change the logo) |
| top.html | Logo, site name, Home - Login - Registration - Catalogue - Cart |
| left.html | CSE, ECE, EEE, CIVIL links (open that branch's catalogue) |
| home.html | Initial right-frame page: description of the web site |
| login.html | User Name, Password, Submit, Reset |
| catalogue.html | Cover, author, publisher, price, Add to cart |
| cart.html | Book name, price, quantity, amount, total amount |
| payment.html | Card / UPI / Net banking / Cash on delivery, with validation |
| register.html | Registration form with JavaScript validation |
| css-demo.html | Selectors, fonts, colours, background-repeat, link pseudo-classes, Bootstrap grid |
| portfolio.html | Mini-project: Developer Portfolio |
| styles.css, script.js | Shared styling and logic, commented |
